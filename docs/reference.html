Diagnosing an empty report

doctor walks all nine adapters and classifies each one — has data, installed but no usage yet, or not found — printing every path it probed, whether that path exists, whether an override variable is active, and one concrete hint per tool.

$ token-finops doctor                  # all adapters
$ token-finops doctor --tool codex     # just one

The recording is on the overview page. doctor is newer than the 0.3.0 release — see the install notes.

JSON output shapes

  • report --json — array of per-tool objects (tool, used_fraction, runway_days, status, …).
  • self-audit --json — session totals plus a by_model breakdown.
  • status --format json — the ~/.token-finops/last.json cache contents (tools, binding, generated_at) plus stale_seconds.

savings flags

Full detail, and the reasoning behind every figure, is on the savings page and the CO2 research page. token-finops savings --list prints the valid values for every enumerated flag below.

FlagWhat it does
--hardware KEYWhich box to price. 8 profiles, from mac-mini-m4-pro-64gb to rtx-5090-workstation, incl. macbook-pro-16-m4-max-48gb.
--model KEYWhich local model, and therefore which cloud tier it is compared against (haiku- / sonnet- / opus-class).
--power KEYElectricity tariff: grid or PV, German or US. PV is priced at the feed-in tariff you forgo, not at zero.
--utilization FFraction of 24/7 the box actually runs inference. Dominates the result, because capex amortises over tokens actually produced.
--own-hardwareDrop capex entirely — the box is already bought, so compare the marginal cost of the next token (electricity) against the API bill.
--co2Add the gCO2e-per-1M-tokens block: the [computed] local figure next to the [ESTIMATE] cloud one, with the confidence line and basis spelled out.
--cloud-region KEYWhich grid the cloud tokens are assumed to burn on, for the --co2 estimate only: us-avg (350 g/kWh, default), us-virginia (270), us-ercot (334), de-grid (344).
--lifetime-years N · --output-share FAmortisation window; share of tokens that are output rather than input (affects the cloud price, which bills them differently).
--listPrint every valid hardware / model / tariff / cloud-region key with its figure and source.

--co2, --cloud-region and --own-hardware are newer than the 0.3.0 release — see the install notes.

Shell tab-completion

Static bash, zsh and fish completion scripts live in contrib/completions/ — subcommand names plus each subcommand's flags, including the enumerated values of --tool, --since, --format, --scenario and the savings keys above. No third-party dependency and no shell startup cost; per-shell install instructions are in docs/INSTALL.md.

Environment-variable overrides

Every adapter reads its data root from an override variable before falling back to the tool's real default location. None of these are required — they exist to point the CLI at a different install, a synthetic fixture tree (see synth), or a non-default $HOME.
