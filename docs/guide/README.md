# The Qvest Digital Guide to Token Burning (formerly: Token Efficiency)

A six-chapter, practitioner-level guide to where token spend actually goes when you use AI coding agents daily, written from inside a repository that measures itself: [00 — Why This Guide Exists](00-why.md) covers the incident that started it and what this guide does and doesn't cover; [01 — What Is a Token, and What Does It Cost?](01-what-is-a-token-and-what-does-it-cost.md) explains the rubber currencies (AI Credits, plan percentages, daily requests) versus pay-per-token pricing and the 15–30x subscription gap; [02 — Where Does the Money Go?](02-where-does-the-money-go.md) breaks down a real self-audited session — cache economics, duplication, sub-agent overhead, and model choice as the dominant cost driver; [03 — Right-Sizing Models](03-right-sizing-models.md) sets out the cheap-models-for-menial-work rule and where it was under-applied in this very repo; [04 — Local vs. Cloud](04-local-vs-cloud.md) works through the local-inference cost formula, German energy constants, and a Mac Studio break-even calculation; and [05 — Governance](05-governance.md) covers soft limits, per-team budgets, individual visibility, and the runway concept, ending with a short checklist and how to contribute an adapter.
