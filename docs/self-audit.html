self-audit

self-audit answers a narrower question than report: what did this Claude Code session cost? It reads the session transcript, splits the usage by model, and attributes sub-agent work to the sub-agents that did it — so a session that farmed cheap work out to Haiku looks different from one that ran everything on the expensive model.

Try it

$ token-finops self-audit                       # the current session
$ token-finops self-audit --config-dir ~/some-other/.claude

self-audit on a Claude Code session that used sub-agents on Sonnet and Haiku.

What to notice: the by-model table is the point. It shows where the tokens actually went, which is usually the difference between "the session was expensive" and "one model in the session was expensive". USD figures are labelled API-equivalent estimates, not a bill — they price the same work as if it had gone through the API.

Recordings are asciicast v2 files committed in docs/casts/ — play them locally with asciinema play <file>. This page ships no analytics and no tracking.
