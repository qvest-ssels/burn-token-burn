self-audit

For: Claude Code users — what a session actually cost, by model and sub-agent. (Not a security audit, despite the name.)

Why the number you'd get by counting is wrong

Claude Code writes one line of usage per content block in a transcript, so counting naively over-reports total tokens by roughly 1.9×. self-audit deduplicates on (message.id, requestId) before adding anything up, and includes sub-agent transcripts in the same pass — a session that farmed cheap work out to Haiku looks different from one that ran everything on the expensive model, and the by-model breakdown below is built to show exactly that. This dedup rationale, not the total, is why the number can be trusted.

self-audit answers a narrower question than report: what did this Claude Code session cost? It reads the session transcript and attributes usage by model and by main-loop-vs-sub-agent.

Try it

$ token-finops self-audit                       # the current session
$ token-finops self-audit --session <id-prefix>
$ token-finops self-audit --config-dir ~/some-other/.claude

self-audit on a Claude Code session that used sub-agents on Sonnet and Haiku.

What to notice: the by-model table is the point. It shows where the tokens actually went — the model, not the raw token count, is what decides the cost. USD figures are labelled API-equivalent estimates, not a bill — they price the same work as if it had gone through the API.

--json, for CI/PR checklists

This repo runs self-audit on itself at the end of every session (see AGENTS.md). The machine-readable form:

$ token-finops self-audit --json
{
  "session": "a1b2c3d4",
  "calls": 214,
  "main": 168,
  "subagents": 46,
  "by_model": {
    "claude-sonnet-4-5": {
      "calls": 190, "input": 812000, "output": 96500,
      "cache_read": 5400000, "cache_write": 210000,
      "reasoning": 0, "usd": 18.42, "usd_known": 190
    }
  }
}

The "sub-agents = N% of API-equivalent cost" line shown by the plain text output is derived from main/subagents and the per-model usd figures above; it isn't a separate JSON field.
